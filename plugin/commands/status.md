---
description: O-Brain에 기억이 잘 쌓였는지 상태를 한국어로 보여줍니다
---

사용자가 O-Brain 상태를 확인하려고 합니다. 아래 명령을 실행하고, 그 출력을 **비개발자도 이해할 쉬운 한국어**로 정리해 보여주세요(총 기억 수, 최근 기억, 마지막 자동 저장이 성공했는지, 의미검색이 정상인지).

```
node "${CLAUDE_PLUGIN_ROOT}/scripts/run-app.mjs" status
```

⚠️ 표시가 있는 줄(의미검색 중단·벡터 누락·구버전 훅·캡처 실패)은 빠뜨리지 말고 원인과 해결 방법을 함께 알려주세요.
기억이 0건이거나 훅이 아직 안 울렸으면, "대화하고 세션을 종료하면 자동으로 쌓인다"고 안내하세요.
`app 폴더를 찾지 못했어요` 같은 메시지가 나오면 O-Brain의 app 폴더에서 `npm run plugin:pin`을 한 번 실행하라고 안내하세요.
