description: 관련 있는 기억끼리 관계(번복/뒷받침/영향/충돌)를 제안하고 연결합니다
---

사용자가 기억들 사이의 관계를 연결하려고 합니다.

1. **대상 찾기**: 사용자가 말한 주제로 `search_memory`(현재 프로젝트 우선) 또는 특정 기억의 `get_related`로 후보를 모읍니다.
2. **관계 제안(추정만)**: 관련 있을 법한 기억 쌍을 골라 "이 둘은 ~관계로 보입니다"라고 *제안*합니다. 단정하지 마세요.
3. **종류는 사용자가 확정**: 관계 종류를 자동으로 정하지 말 것(틀린 자동관계 방지 — PRD 원칙). 사용자에게 종류를 확인받습니다.
4. **연결**: 사용자가 확정한 것만 `add_relation` 도구로 연결 — `from_id`, `to_id`, `type`:
   - `SUPERSEDES`=번복(대체) · `SUPPORTS`=뒷받침 · `INFLUENCES`=영향 · `CONTRADICTS`=충돌
5. 끝나면 **무엇을 몇 건 연결했는지 쉬운 한국어로** 요약합니다.

비고: 같은 두 기억의 같은 관계는 중복 저장되지 않습니다. 잘못 연결하면 대시보드(`/o-brain:open`)에서 관계 삭제/되돌리기로 정리할 수 있습니다.
