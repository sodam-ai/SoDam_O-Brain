---
description: O-Brain 대시보드를 브라우저로 띄웁니다 (서버 자동 시작)
---

사용자가 O-Brain 대시보드 화면을 보려고 합니다. 아래 명령을 실행하세요. 서버가 꺼져 있으면 켠 뒤 기본 브라우저로 대시보드를 엽니다(켜져 있으면 그대로 엽니다).

```
node "${CLAUDE_PLUGIN_ROOT}/scripts/run-app.mjs" open
```

실행 후 출력에 나온 주소를 넣어 한국어로 이렇게 알려주세요:
"O-Brain 대시보드를 띄웠습니다 — 브라우저 창을 확인하세요 (출력된 주소). 다음부터는 이 주소를 즐겨찾기에 추가하면 클릭 한 번으로 다시 열 수 있어요."

⚠️ 메시지(서버가 안 켜짐, app 폴더를 찾지 못함)가 나오면 그대로 쉬운 말로 전하고 해결 방법을 안내하세요
(app 폴더를 못 찾으면 O-Brain의 app 폴더에서 `npm run plugin:pin`을 한 번 실행).
