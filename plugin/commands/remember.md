---

사용자가 이번 대화의 중요한 내용을 O-Brain에 기억시키려고 합니다. (자동 저장이 놓치거나 더 정확히 남기고 싶을 때 쓰는 수동 저장입니다.)

1. **최근 대화를 훑어** 또렷한 **결정·약속·제약·선호·지식**만 골라냅니다.
   - 저장 대상: 사용자가 분명히 "정하자/쓰자/금지/선호한다" 처럼 정한 것.
   - 제외: 잡담, `cd` 같은 단순 명령, 추측, **내(AI)가 한 말**, 주입된 시스템/스킬 텍스트.
2. 고른 항목마다 **`save_memory` 도구(MCP 서버 `o-brain`)** 를 호출해 저장합니다:
   - `content`: 한 문장으로 명확히 (예: `이 프로젝트 테스트 포트는 7740으로 정하자`)
   - `type`: `결정` / `제약` / `선호` / `패턴` / `지식` 중 하나
   - `importance`: 1~5 (중요할수록 큰 값)
   - `project`: 현재 작업 폴더 절대경로(cwd)
3. 저장이 끝나면 **무엇을 몇 건 저장했는지 쉬운 한국어로** 요약해 알려줍니다.

비고:
- 시크릿(API 키·비밀번호 등)은 저장 직전 **자동으로 가려집니다**(`[REDACTED]`).
- 저장할 또렷한 결정이 없으면 "기억할 만한 결정이 없었어요"라고 알려주세요.
- 같은 내용을 반복 저장하지 않도록, 이미 있을 법한 기억은 먼저 `search_memory`로 확인 후 저장하세요.
