# O-Brain — 내 AI의 기억 노트 🧠

> 클로드코드와 나눈 대화에서 **중요한 결정·약속·취향을 자동으로 기억**하고,
> **그래프·타임라인으로 보여주는** 100% 내 컴퓨터(로컬) 도구.

**비유 한 줄:** AI는 똑똑하지만 대화가 끝나면 다 잊는 *건망증 친구*. O-Brain은 그 친구 옆에 두는 **자동 메모 노트**입니다. 중요한 말을 알아서 적어두고, 다음에 다시 알려줘요.

---

## 무엇을 해주나요?
- **자동 저장**: 클로드코드 대화를 끝낼 때, "포트는 7740으로 정하자" 같은 **결정·약속·금지**를 사람 손 없이 자동으로 적어요.
- **자동 가림(보안)**: 비밀번호·API키 같은 건 적히기 전에 **자동으로 가려집니다**(`[REDACTED]`).
- **그래프로 보기**: 쌓인 기억을 **점과 선**(2D/3D 그래프)으로 한눈에 — **시작 화면이 바로 그래프**예요. **목록·타임라인**으로도 봅니다.
- **개요 한눈 요약**: 전체 기억 수·유형/주제/**프로젝트별** 분포·가장 많이 연결된 기억·자주 본 기억을 한 화면에 (**개요** 탭).
- **기억끼리 연결**: "이 결정이 저걸 **번복/뒷받침/영향/충돌**" 처럼 관계를 이어 그래프에서 **색깔 선**으로 봐요. **연결할 대상은 자동 추천**(유사도)되니 클릭만 하면 됩니다.
- **주제별 자동 분류**: 기억을 보안·UI·배포 등 **주제**로 자동 묶고, 그래프에서 **'분류색'** 버튼으로 주제별 색을 볼 수 있어요.
- **편하게 보기**: 검색·유형/**프로젝트** 필터·정렬·**밝게/어둡게 테마**·**기억 수정(편집)**·내보내기(JSON/마크다운)·삭제. **⌘K(Ctrl+K)** 로 어디서든 빠르게 검색·이동.
- **AI가 직접 활용**: 새 대화를 시작하면 관련 기억을 자동으로 불러오고(최근·신뢰도 높은 것 우선), 대화 중에도 기억을 **검색·관계 추적·결정 변천 조회**해서 씁니다.
- **프로젝트 자동 분류**: 기억이 **그 세션에서 실제로 편집한 파일이 속한 프로젝트**로 자동 분류돼요(클로드코드를 어디서 켰든 상관없이, 가장 많이 만진 프로젝트로).
- **자동 새로고침**: 새 기억이 생기면 화면이 **알아서 반영**돼요(탭으로 돌아오거나 잠시 기다리면). 오른쪽 위 **새로고침(↻) 버튼**으로 즉시 갱신도 가능.
- **100% 로컬**: 모든 게 내 컴퓨터 안에만 있어요. 인터넷으로 안 나갑니다.

## 1. 사전 준비물
- Windows PC
- **Node.js**(LTS) — 없으면 [nodejs.org](https://nodejs.org)에서 설치 후 **창을 새로** 여세요
- **클로드코드**(Claude Code)
- 인터넷(설치할 때만)

## 2. 설치 (딱 2단계)
> 모두 **클로드코드 입력칸**에 그대로 칩니다.

**① 목록 등록**
```
/plugin marketplace add D:\AI_Dev_Work\2026y\26y_06m_21d_SoDam_O-Brain\plugin
```
**② 설치**
```
/plugin install o-brain@o-brain-local
```
→ 설치되면 **클로드코드를 새로 시작**하면 끝.

> `o-brain`=플러그인 이름, `o-brain-local`=목록 이름.
> 혹시 "git repo가 아니다"로 ①이 막히면, 그 폴더에서 `git init && git add -A && git commit -m init` 후 다시.

## 3. 잘 깔렸는지 확인
클로드코드 입력칸에:
- `/o-brain:status` → 쌓인 기억·상태 보기
- `/o-brain:selftest` → 두뇌(저장·보안·검색) 한 방에 점검 (✅✅✅이면 정상)

## 4. 사용법 (제일 중요 — 아주 쉬움)
1. **평소처럼 대화**하다가, 기억시킬 건 **또렷한 결정 문장**으로 말하세요.
   예) `이 프로젝트 테스트 포트는 7740으로 정하자`
   *(`cd` 같은 단순 명령·잡담은 안 적혀요. "정하자/쓰자/금지" 같은 말만 골라 적습니다.)*
2. 그 대화를 **끝내기**: 입력칸에 `/clear` (또는 창 닫기). → 이 순간 자동 저장.
3. 확인: `/o-brain:status` → **기억 수가 늘고**, 그 문장이 목록에 보이면 성공.

## 5. 화면(대시보드)으로 보기
**가장 쉬운 방법** — 클로드코드 입력칸에:
```
/o-brain:open
```
→ 서버가 꺼져 있어도 자동으로 켜고 브라우저로 대시보드를 엽니다.
*(또는 저에게 "화면 켜줘"라고 해도 되고, 수동으로는 `! cd D:\AI_Dev_Work\2026y\26y_06m_21d_SoDam_O-Brain\app; npm start` 후 브라우저에서 `http://127.0.0.1:7740/`.)*

화면에서 할 수 있는 것:
- **그래프(첫 화면) · 개요 · 목록 · 타임라인** 탭 전환. 위 검색창(`/` 키로 바로 이동), **⌘K(Ctrl+K)** 로 명령·기억 빠른 검색, 항목 클릭 시 상세.
- **개요** 탭: 전체 수·유형/주제/**프로젝트별** 분포·가장 많이 연결된 기억·자주 본 기억을 한눈에. **"연결 없는 기억"**을 누르면 그래프에서 외톨이 기억만 모아 봅니다.
- 상세창에서 **복사 · 편집(내용/유형/중요도) · 삭제**, 그리고 **"이 기억의 관계"** 에서 다른 기억과 번복/근거/영향/충돌로 **연결**. 이때 **"관련 있을 만한 기억"이 자동 추천**돼서, 누르면 대상이 채워지고 **종류만 고르면** 돼요. *(편집 시에도 시크릿은 자동으로 다시 가려집니다.)*
- 오른쪽 위 **새로고침(↻)**·**밝게/어둡게 테마**·**내보내기**(JSON/마크다운), 유형·**프로젝트** **필터·정렬**. *(새 기억은 잠시 후/탭 복귀 시 자동 반영되고, 프로젝트는 최근 활동순으로 보여요.)*
- 그래프에서 점에 마우스를 올리면 연결된 기억이 강조되고, 검색하면 해당 점이 밝아집니다. 그래프 위 **'분류색'** 버튼으로 점 색을 유형↔주제(분류)로 바꿀 수 있어요.
- **중요도·기간 필터**로 좁혀 보고, 상세창 **표적(◎) 버튼**으로 *그 기억 중심(이웃만)* 보기, **자주 열어본 기억일수록 점이 더 밝게** 빛나요(조회수). 기억이 많아지면 그래프는 **가장 중요한 것 위주로** 보여주고 *"전체 N개 중 상위 M개"* 로 알려줘요.

## 6. 백업 & 복원 (소중한 기억 보호)
- **백업**: `/o-brain:backup` (또는 `npm run backup`). 서버 켤 때도 자동 백업돼요.
  - 저장 위치: `D:\AI_Dev_Work\2026y\26y_06m_21d_SoDam_O-Brain\app\data\backup\` (최신 7개 보관)

  `app\data\obrain.db` 로 **복사해 덮어쓰기** 하면 됩니다. (먼저 현재 파일을 다른 데 복사해 두세요)

## 9. 문제해결 (실제 겪은 것 위주)
| 증상 | 원인 | 해결 |
|------|------|------|
| `Marketplace not found` | 한 번에 설치 시도 | **2단계**(목록 등록 → 설치) 순서대로 |
| 기억이 안 쌓임 | "결정/약속" 문장이 없었음 / 세션 안 끝냄 | 또렷한 결정 문장 말하고 **`/clear`** |
| 화면(주소)이 안 열림 | 서버 안 켜짐 / 포트 점유 | `npm start` 다시, 또는 `.env.local`에서 `OBRAIN_PORT` 변경 |
| 새 대화에서 엉뚱한 포트로 답함 | **다른 메모리 도구와 충돌**(아래 한계 참고) | 알려진 한계 — `search_memory`로 직접 찾기 |
| `'node'은 명령이 아닙니다` | Node.js 미설치 | nodejs.org에서 LTS 설치 → **새 창** |
| 3D 그래프가 안 보임 | WebGL 미지원·저사양 | **2D**로 전환 |
| 새 기억·프로젝트가 화면에 안 보임 | 화면이 옛 상태 | **새로고침(↻) 버튼** 누르기(또는 잠시 후 자동 반영) |
| 프로젝트가 한 개로 합쳐져 보임 | 옛 기억은 예전 방식(시작 폴더)으로 저장됨 | **다음 `/clear`부터** 실제 작업한 프로젝트로 자동 분류됨(옛 기억은 그대로) |
| git repo 아니라고 설치 거부 | 로컬 폴더 | `plugin` 폴더에서 `git init && git add -A && git commit -m init` |

## 12. 솔직한 한계 (현재 v0.1)
- **되읽기 충돌**: 이 PC에 다른 메모리 도구(memory-bank·페르소나 메모리)가 함께 있어, "포트?" 같은 질문에 **옛/충돌 기억이 섞여** O-Brain의 최신 기억이 묻힐 수 있어요. (개선 예정)
- **추출은 규칙 기반**: 또렷한 결정 문장은 잘 잡지만, 미묘한 맥락은 놓칠 수 있어요. (AI 추출 모드는 다음 단계)
- **기억 관계 연결**: *연결할 대상*은 유사도로 **자동 추천**되지만, *관계 종류*(번복/뒷받침/영향/충돌)는 **사람이 직접** 고릅니다. (종류까지 자동 판정은 틀릴 수 있어 일부러 사람이 결정 — 잘못된 자동 관계 방지.)
