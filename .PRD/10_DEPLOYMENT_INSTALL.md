>

> 사유(확인됨): `.bat`은 'Windows에 Node 앱 설치'엔 쓸모 있어도, **'클로드코드/코덱스 통합' 메커니즘이 아님.**

## 0. 핵심 구분 (이게 핵심)

**"클로드코드/코덱스에 통합"** ≠ **"Windows에 앱 설치"** — 둘은 다른 문제다.
- **통합**: 네이티브 방식(플러그인 / MCP)으로. ← 제대로 붙는 길
- **설치 편의**: Node·의존성·로컬 서버 셋업. ← `.bat`은 여기서만 보조

---

## 1. 배포 형태 (정정된 결정)

| 대상 | 정식 방법 | 근거 |
|------|----------|------|
| **클로드코드** | **플러그인으로 배포** — 캡처 훅(SessionEnd)·되읽기(SessionStart)·MCP 도구를 **하나의 플러그인에 번들** → `/plugin install`(또는 마켓플레이스) | memory-bank·claude-mem이 동일 방식(확인됨) |
| **코덱스** | **MCP 서버 등록**(코덱스 config의 mcp_servers) + 세션 로그 파일 폴백 | 코덱스 훅 미성숙 가능성 우회(02·03과 일관) |
| **그래프 GUI** | 플러그인/명령이 띄우는 **로컬 웹 서버(localhost)** → 브라우저로 열기 | 클로드코드 안엔 웹 GUI를 못 그림 → 별도 로컬 앱 |
| **(보조) 스크립트** | 비개발자용 Node·`npm install`·`db:init`·로컬앱 실행 **헬퍼**. **통합 수단 아님** | `.bat`로 settings 직접 편집은 깨지기 쉬움 → 지양 |

> 결정: **클로드코드=플러그인 / 코덱스=MCP / GUI=로컬서버**. 설치 편의 스크립트는 어디까지나 보조.

## 2. 패키지 구성 (플러그인 + 로컬 앱)

```
obrain/                      (배포 단위)
├─ plugin/                  ← 클로드코드 플러그인
│   ├─ plugin manifest      (hooks·mcp 선언)
│   ├─ hooks/               (SessionEnd 캡처 / SessionStart 주입)
│   └─ mcp/                 (search_memory 등 MCP 서버)
├─ app/                     ← 로컬 웹 앱(그래프·타임라인 GUI)
│   ├─ server/  web/
└─ (보조) setup 스크립트     (Node·deps·앱 실행 도움)
```
> 훅·MCP는 **플러그인 매니페스트가 선언** — 사용자가 `settings.json`을 손으로 안 고쳐도 됨(안전·업데이트 용이).

---

## 3. 네이티브 빌드 위험 + 대안 (R5 — 유지)

- `better-sqlite3`는 네이티브 모듈 → Windows 빌드 실패 가능(확인됨).
- 대응: ① prebuilt 바이너리 버전 고정 ② Node LTS 고정 ③ 폴백 `node:sqlite`/`sql.js`(WASM, 네이티브 불필요). 0단계 실측 후 택1.

---

## 4. 설치 흐름

1. **클로드코드**: `/plugin install`(마켓플레이스 또는 로컬 경로)로 O-Brain 플러그인 설치 → 훅·MCP 자동 등록.
2. **코덱스(선택)**: 코덱스 config에 O-Brain MCP 서버 등록(안내 제공).
3. **로컬 앱(그래프)**: 최초 1회 의존성 셋업(보조 스크립트가 Node 확인·`npm install`·`db:init`) → 이후 명령/플러그인이 로컬 서버 실행.
4. `.env.local` 추출 모드(ai/rule)·키 설정.

> 비개발자 배려: 1·3을 한 번에 안내하는 **셋업 도우미**(스크립트 또는 플러그인 명령)를 제공하되, "클로드코드 설치"는 어디까지나 **플러그인 설치**임을 분명히.

## 5. 업데이트 / 6. 제거

- **업데이트**: 플러그인 업데이트(`/plugin` 경로) + 로컬 앱 `npm install` + **스키마 마이그레이션**(schema_version, 기억 데이터 보존). 업데이트 전 data 자동 백업.
- **제거**: 플러그인 제거(훅·MCP 자동 해제) → 로컬 앱 폴더 삭제는 **data 백업 안내 + YES 확인 게이트** 뒤에서만. 자동 삭제 금지.
