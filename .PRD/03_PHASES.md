## Phase 1: MVP (예상 5~7주)

> ⚠️ 범위 주의(PM 관점): Phase 1이 큼(훅·추출·보안·저장·검색·웹·2D/3D그래프·타임라인). **1a(자동저장+검색+목록) → 1b(2D/3D그래프+타임라인)** 두 마일스톤으로 쪼개 각자 '실제 동작'을 확인하며 진행 권장. 시각화는 유지하되 순서만 분리.

### 목표
클로드코드 세션을 끝내면 **자동으로** 기억이 저장되고, 웹에서 그 기억들을 **검색 + 풍부한 2D/3D 지식그래프 + 타임라인**으로 탐색할 수 있다. (차별점인 시각화를 첫 버전부터 제대로)

### 기능
- [ ] 클로드코드 자동 연동(훅) — 세션 시작~종료 캡처
- [ ] 자동 기억 추출 (결정/선호/패턴/지식/제약 유형 분류)
- [ ] **보안 필터** — 저장 전 비밀번호·API키·토큰 자동 제거
- [ ] 로컬 저장 (SQLite: 프로젝트·세션·기억·연결·분류 + 시각화/시간 필드)
- [ ] 똑똑한 검색 (의미 + 키워드 하이브리드, 관련 기억만 소량 반환=토큰 절약)
- [ ] 웹 대시보드 — 프로젝트별 기억 목록·상세 열람
- [ ] **풍부한 지식그래프 시각화 (핵심)** — 2D/3D 토글, 노드 색=분류, 크기=중요도+연결수, 글로우=접근빈도, 모순=빨강 점선, 호버/클릭/검색 하이라이트/필터, 로컬↔글로벌 그래프 (→ 01_PRD §8)
- [ ] **타임라인 뷰(기본)** — 기억의 시간 흐름·진화선 표시
- [ ] **성능 가드** — WebGL 렌더, 노드 수 상한·필터·라벨 지연표시 (무거워도 프리징 방지)
- [ ] 관계 '표시' — 대체함·모순됨 등 관계를 그래프·타임라인에 보여주기 (자동 정리는 아직 X)

### 데이터
- 프로젝트, 세션, 기억(+access_count·valid_from/until·invalidated_by), 연결, 분류
- scope 기본 `project` 저장 / 분류 기본 시드(결정·보안·UI·배포·도구·성능·데이터·기타) 제공
- 기억에 confidence(추출 신뢰도)·source(ai/rule/user) 기록 — 오추출 구분(R7)

### 인증
- **없음** (내 PC 1인 전용 로컬 도구)

### "진짜 도구" 체크리스트 (로컬 도구 버전)
- [ ] 실제 SQLite 파일 연결 (목업/하드코딩 데이터 X)
- [ ] 실제 클로드코드 훅이 실제 세션에서 동작 (가짜 트리거 X)
- [ ] 실제 로컬 임베딩으로 의미검색 동작 (검색 흉내 X)
- [ ] 보안 필터가 실제로 시크릿을 제거 (테스트로 검증)
- [ ] 그래프가 실제 DB 기억을 2D/3D로 렌더 (목업 노드 X)
- [ ] 수천 노드에서도 필터·WebGL로 멈추지 않음 (성능 실측)
- [ ] 데이터가 외부로 안 나감 — 네트워크는 "기억 추출 AI 호출"에만 한정

- ~~"기억을 똑똑하게 뽑는 순간"만 사용자의 기존 클로드 구독/API 키로 AI(기본 Haiku)에게 맡긴다~~ →

  구독 중인 세션)** 을 수동 호출. 그 대화 내용은 **외부에 영구 저장하지 않음** — 원칙은 그대로 유지.

## Phase 2: 확장 (예상 3~4주)

### 전제 조건
- Phase 1이 안정적으로 내 PC에서 매일 쓰이는 상태

### 목표
코덱스까지 **정식**으로 자동 기억하고, 웹에서 기억을 **직접 고치고**, 관계가 **자동으로** 연결되며, **시간여행**으로 과거 상태를 재현한다.

### 기능
- [ ] 코덱스 정식 연동 — **훅이 있으면 훅, 없으면 세션 로그 파일 읽기 폴백**(확정)으로 캡처
- [ ] 웹에서 기억 직접 편집·삭제·중요도·관계 조정
- [ ] 관계 자동 연결 (영향줌·대체함·모순됨을 AI가 자동 추론)
- [ ] 온톨로지(분류) 자동 태깅 + 그래프 그룹/색 필터
- [ ] **시간여행·진화 추적** — "이 시점에 무엇을 알았나" 쿼리, 결정 변천사(타임라인 강화)
- [ ] **신뢰도 감쇠** — 강화 안 된 오래된 기억은 신뢰도↓로 순위 하락(삭제 X). 근거: Memento 반감기(정독)
- [ ] **그래프 고급** — 고아(연결 없는) 기억 감지, 새 연결 추천
- [ ] 검색 고도화 (관련 기억 자동 첨부 = RAG, 3단계 점진 공개로 토큰 절약)

### 통합 테스트
- Phase 1 기능(자동 저장·검색·그래프·타임라인)이 여전히 정상인지 확인
- 코덱스·클로드코드 기억이 한 그래프에 섞여도 충돌 없는지 확인

## Phase 3: 고도화 (예상 4~6주)

### 전제 조건
- Phase 1 + 2가 안정적으로 운영 중

### 목표
기억이 많아져도 **스스로 깔끔하게 정리**되고, 다른 AI 도구까지 확장하며, 그래프 분석·백업을 제공한다.

### 기능
- [ ] 중복·모순 기억 자동 정리 (비슷한 기억 병합 **임계 코사인 0.92**, 진화 추적 자동화) — 근거: claude-knowledge-graph(정독)
- [ ] 멀티 도구 확장 (제미나이·커서 등)
- [ ] **그래프 분석 알고리즘** (중심성·최단경로·blind spot 자동 발견 — Cytoscape 보조)
- [ ] 백업·내보내기 (Markdown / JSON)

### 주의사항
- **자동 정리는 위험** — 잘못 병합하면 기억 손상. "되돌리기(undo)" + 사용자 확인 게이트 필수. 자동 삭제 금지.
- **비용** — 자동 관계 추론·정리에 AI 호출이 늘면 사용량 증가. 호출량을 사용자에게 표시.
