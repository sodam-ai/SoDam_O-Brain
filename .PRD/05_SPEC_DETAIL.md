## 2. 보안·프라이버시 상세

> 전체 보안 요구사항(OWASP ASVS L1·인젝션·로컬 접근통제·우선순위)은 **08_SECURITY.md** 참조. 아래는 요약.

- **데이터 위치**: `OBRAIN_DATA_DIR`(기본 `./data`) 안 SQLite 단일 파일. 외부 전송 없음. 네트워크/클라우드 드라이브·WSL2 `/mnt` 저장 지양(SQLite 락·유출 — codegraph 교훈, 정독 확인).
- **원문 대화 미저장**: **추출된 기억 + 세션 요약만** 저장, 대화 원문 전체는 저장 안 함 → 저장 폭주(sprawl) 방지 + 노출 최소화. (근거: Graphiti의 episode sprawl 경고 — 정독 확인)
- **시크릿 필터(저장 전 필수)** — 마스킹 대상 패턴(예):
  - API 키(`sk-...`, `AKIA...`, `ghp_...`, `AIza...`), Bearer 토큰, `.env` 값, 비밀번호 유사 문자열, 사설키 블록(`-----BEGIN ... KEY-----`)
  - 매칭 시 `[REDACTED]`로 치환 후 저장. (근거: agentmemory privacy filter — 확인됨)
- **AI 호출 정책**: `ai` 모드에서만, **추출 순간만** 호출. 대화 원문 외부 영구저장 금지. 호출 시각·이유를 사용자에게 표시.
- **키 보관**: `ANTHROPIC_API_KEY`는 `.env.local`에만. 코드·그래프·로그에 노출 금지.

## 3. 에러 처리·실패 모드 (silent failure 금지)

| 실패 상황 | 동작(fail-safe) | 사용자 표시 |
|------|------|------|
| AI 추출 실패/타임아웃 | `rule` 폴백 자동 전환 | "AI 추출 실패 → 규칙 기반으로 저장함" |
| 훅 신호 누락(코덱스 등) | 세션 로그 파일 폴백 | 조용히 폴백 + 로그 기록 |
| 임베딩 생성 실패 | 키워드(FTS5) 검색만 일시 동작 | "의미검색 일시 중단" 배너 |
| sqlite-vec 로드 실패 | 키워드 검색 유지 + 경고 | 확장 설치 안내 |
| DB 손상 | 읽기 전용 + 백업 복구 권유 | 경고 |

> 원칙: 실패해도 fail-safe로 우회하되, **반드시 사용자에게 가시화**(은폐 금지). `--force`/무시 같은 은폐성 우회 금지.

## 9. 용어집 (비개발자용)

- **훅(hook)**: AI 도구가 특정 순간(세션 종료 등)에 자동으로 부르는 "알림 트리거".
- **임베딩(embedding)**: 문장을 숫자 좌표로 바꿔 "의미가 비슷한지" 재는 기술.
- **온톨로지(ontology)**: 지식을 주제·관계로 분류하는 체계.
- **FTS5**: SQLite의 빠른 키워드 검색 기능.
- **sqlite-vec**: SQLite에서 의미(벡터) 검색을 하는 확장.
- **RRF**: 키워드+의미 검색 결과를 똑똑하게 합치는 방법.
- **노드/엣지**: 그래프의 점(기억) / 선(관계).
