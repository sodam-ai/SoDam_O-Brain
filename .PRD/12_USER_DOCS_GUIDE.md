## 2. README/가이드 필수 섹션 체크리스트 (초보자 눈높이)

- [ ] **이게 뭔가요?** — 한 문단 + 무엇을 해주는지(클로드코드·코덱스 기억을 자동 저장·그래프로 보기)
- [ ] **사전 준비물** — Windows PC, 인터넷(설치/AI추출 시만), 클로드코드, (선택)Anthropic API 키
- [ ] **필요 프로그램** — Node.js(권장 버전 명시) · 클로드코드 — 각 **다운로드 링크 + 설치 그림**
- [ ] **다운로드 방법** — 어디서 받나(GitHub/폴더), 압축 푸는 법, 둘 위치
- [ ] **설치 방법** — ① 클로드코드 플러그인 설치(`/plugin install`) ② 로컬앱 셋업(클릭/명령) (10 기준)
- [ ] **실행 방법** — 어떻게 켜나, **localhost 주소 여는 법**(브라우저에 주소 입력)
- [ ] **사용·작동 방법** — 평소대로 AI와 작업 → 세션 끝나면 자동 저장 → 웹에서 그래프·검색·타임라인
- [ ] **빠른 시작(5분)** — 최소 단계만 번호로
- [ ] **워크플로우 그림** — 대화 → 자동저장 → 웹 탐색 → AI 자동참고
- [ ] **파일·문서 위치** — 기억 DB 저장 위치(**절대경로**), 설정 파일(`.env.local`), 백업 위치, 문서 위치
- [ ] **명령어 목록** — **복붙 가능한 표**(설치·실행·DB초기화·업데이트·제거) + 각 한 줄 설명
- [ ] **문제·오류 대처** — §4 카탈로그
- [ ] **안전·개인정보** — 100% 로컬, 시크릿 자동제거, 데이터는 사용자 책임(08·09)
- [ ] **라이선스·보증없음** — 09 기준(쉬운 말로)

## 3. 작성 규칙 (초보자 친화 — 필수)

- 명령어는 **한 줄씩 복붙 가능**하게(여러 줄 한 덩어리 금지).
- 경로는 **절대경로**로(예: `D:\...\O-Brain\data`). 빌드 산출물 위치는 **반드시 절대경로로 안내**(초보자는 위치를 못 찾음).
- 용어는 **그 자리에서 괄호 풀이**.
- 스크린샷 들어갈 자리는 `[그림: 무엇무엇 화면]`으로 표시.
- 위험·비가역 단계(삭제·덮어쓰기)는 **빨강/⚠️ 경고 + "멈추고 확인"**.
- **"이렇게 나오면 정상입니다"** 예시 출력을 함께(초보자 안심).

## 4. 예상 불편·빈틈·위험·오류·변수·충돌·실패 카탈로그 (상세) ★

> 초보자가 **실제로 겪을** 상황. 각 항목 **증상 → 원인 → 해결**. README 문제해결 섹션의 뼈대.

| 증상 | 원인 | 해결 |
|------|------|------|
| `'node'은(는) 명령이 아닙니다` | Node.js 미설치 | nodejs.org에서 LTS 설치 → **창을 새로 열어** 재시도 |
| "Windows가 PC를 보호했습니다"(SmartScreen) | 미서명 실행 | 신뢰 시 **추가 정보 → 실행**. 신뢰 안 되면 멈춤 |
| 다운로드 파일 차단/잠김 | 백신·"다른 PC에서 옴" 표시 | 파일 우클릭 → 속성 → **차단 해제(Unblock)**, 백신 예외 |
| `better-sqlite3` 설치 실패 | 빌드 도구 없음(네이티브 모듈) | prebuilt 버전 사용/대안(`sql.js`)로 폴백 — 안내문 제공(R5·10) |
| 포트 충돌(주소가 안 열림) | 다른 앱이 같은 포트 점유 | `.env.local`에서 **포트 변경**(예: 7333→7334) |
| 설치/실행에 관리자 권한 요구 | 설치 위치 권한 부족 | **사용자 폴더**에 설치(관리자 불필요) |
| 플러그인 설치 안 됨 | 경로/버전/마켓 미등록 | `/plugin install` 재시도, **수동 등록 안내** 따라하기 |
| AI 키가 안 먹힘 | `.env.local` 오타·위치 틀림 | 형식·위치 확인, 안 되면 **`rule` 모드(키 불필요)** |
| 한글/공백 경로 오류 | 경로에 한글·공백 | **영문·공백 없는 경로**에 설치 권장 |
| 브라우저가 자동으로 안 열림 | 자동 실행 실패 | 브라우저에 **`localhost:포트` 직접 입력** |
| 3D 그래프가 안 보임/끊김 | WebGL 미지원·저사양 | **2D로 토글**, 필터로 노드 줄이기(06 성능 가드) |
| 기억이 안 쌓임 | 훅 미등록·세션 안 끝남 | 훅 등록 확인, **세션을 실제로 종료**했는지 확인 |
| 검색 결과가 비어 있음 | 임베딩 미생성·모델 로딩 | 키워드 검색으로, 모델 첫 로딩 대기·재색인 |
| 데이터가 사라질까 걱정 | 폴더 이동·삭제 | **백업 위치·복사법 안내**(05 백업), 클라우드 드라이브 저장 금지(08) |
| 업데이트 후 동작 이상 | 스키마 마이그레이션 문제 | **백업에서 복구**(업데이트 전 자동 백업 — 10) |
| 인터넷 없음 | AI 추출 호출 실패 | **`rule` 모드(100% 오프라인)** 로 전환 |

> 각 항목에 **"이건 위험하니 멈추고 확인"** 표시를 넣고, 데이터 손실 우려 작업은 백업 먼저.
